# SB-10 — Audible lineage recognition

The native family study compares a parent phenotype, a deterministic sibling
branch, and an intentionally distant unrelated phenotype. Listen in the order
listed by [`seed_lineage_comparison.json`](../fixtures/seed_lineage_comparison.json),
then inspect the matching control ledger. The parent/sibling distance must stay
below the parent/unrelated distance; the native test guards that relation.

This is a structural resemblance proof: correlated density, contour, tone,
space, recurrence, and tension remain near their parent under a bounded branch.
It does not promise identical waveforms or add ancestry storage, which remains
the scope of SB-11.
